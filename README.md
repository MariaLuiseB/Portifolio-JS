```bash
projeto-portfolio/
│
├── assets/
├── css/
├── js/
├── index.html
└── README.md
```

---

## 💻 Como Executar o Projeto

1. Clone o repositório:

```bash
git clone https://github.com/MariaLuiseB/Portifolio-JS.git
```

2. Acesse a pasta do projeto:

```bash
cd Portifolio-JS/projeto-portfolio
```

3. Abra o arquivo `index.html` no navegador.
